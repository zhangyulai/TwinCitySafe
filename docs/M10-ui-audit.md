# M10 UI / Design Audit

审查基线：M1–M9 验收和当前 Vue / Three.js / ECharts 接口。M10 保留已有引擎、预测、拓扑、回放合同，增量优化展示层。

| 区域 | 现状与问题 | M10 处理 | 保留边界 |
|---|---|---|---|
| 设计系统 | 全局、运维、管网、预测与复盘重复定义蓝色、字号和卡片 | 建立背景、文字、强调色、风险等级、圆角、间距 tokens，统一可收缩网格与错误/空状态 | 风险颜色含义保持一致，不改变评分 |
| Dashboard | 天气与 P03 细项占据首屏；`system.onlineDevices` 是旧汇总；底部仍显示 M9 回放占位 | 首层园区运行态、设备在线/异常、管网与当前事故；中央三维主视觉；真实档案和三种快捷入口 | 不创造综合安全分，不把无事故等同所有资产正常 |
| Dashboard 水位图 | yAxis.max=3 会截断实际事故水位 | 纵轴按真实观测自适应，保留原 60 点缓存 | 不改采样或平滑真实值 |
| 运维 | 健康/异常/实时读数已齐全，资产与建议细项密集 | 保留 P03 默认选择，以状态、健康和异常为优先，统一字号与卡片 | Isolation Forest 缺失时保留规则健康与说明 |
| 地下管网 | 正常/事故模式入口相同视觉权重，页面残留 M8 与直接 DEV 开关 | 两模式明确选中态，真实资产统计与事故状态区分，开发入口显式 env 开启 | 保留三维、二维拓扑、追踪、隔离的人机交互 |
| 风险研判 | M6 和 XGBoost/TreeSHAP 术语重复，完整技术表常驻 | 优先当前风险与 10/20/30 分钟预测、物理对照与解释；模型详情可展开 | 算法身份、数据规模、真实指标和降级文案仍可见 |
| 应急推演 | 事故、预测、方案纵向信息较密，留有 M3/M7 文案 | 增加演化→预测→人工方案阶段提示，统一布局，保留 Three 实例 | 不自动选方案、不伪造风险下降 |
| 事件复盘 | 完整功能已具备，历史身份与控制应更突出 | 强化历史回放标识、事件选择和时间轴；统一表格/按钮 | 所有 unknown 与缺口继续标记，不倒填历史 |
| 图表 | 四处独立 init，缺少组件局部异常兜底，样式不统一 | 注册共享主题；统一轴、tooltip、legend；错误仅占当前图表，可重试 | 单实例 setOption / dispose，保留测试 debug 与事件 |
| 设备适配 | 各页面宽度断点独立，局部 flex 项缺少 min-width | 验收 1920/1440/1366；允许纵向滚动和技术细节折叠 | 不用裁切/隐藏关键业务内容换取无溢出 |

页面测试 ID、路由和原业务动作保留。开发参数默认隐藏，正式 Demo 独立；确认文案和人工确认不变。真实网络与资源测试由主代理统一顺序运行，避免多个页面同时控制同一仿真引擎。
