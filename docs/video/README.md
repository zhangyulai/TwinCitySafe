# 五分钟真实操作录像

七分钟全板块新版已完成：项目根目录 `TwinCitySafe-7min-all-modules-demo.mp4`，包含中文配音、同步单行字幕及常驻鼠标高亮。章节与验证见 [七分钟说明](seven/README.md)。以下保留五分钟版本记录。

最新文件：项目根目录 `TwinCitySafe-5min-final-demo.mp4`。仅烧录一行统一 30px 的字幕，移除旧底栏的阶段标题和小字说明。编辑用 SRT 放在 `docs/video/subtitles/`，不与视频同目录，避免播放器自动加载后重复显示。

来源为浏览器连续录屏：1920×1080，25 FPS，H.264，300秒。新版提供中文合成解说、大号常驻黄色鼠标、点击目标高亮和名称提示。字幕使用同一份解说文本与语音服务返回的逐词时间戳，按实际操作节点对齐并烧录到画面。中文字幕和鼠标指示仅用于说明录制操作，不修改业务数值。

录制过程实际打开本地页面、使用真实 REST/WebSocket、操纵 Three.js 相机、启动软件事故、查看 XGBoost/物理预测、选择并执行方案。最后操作已关闭事故的时间轴并实时播放历史。画面字幕明确区分现场仿真与历史回放。

暴雨和泄漏片段为本次现场运行，演示切换使用正式重置并保留中止档案；完整已关闭档案来自此前保存的真实仿真。未声称本次录像在五分钟内完成两个新事故的工单关闭。

视频保持真实墙钟速度连续录制；应用内事故速度为10×，历史播放为5×，都通过页面控制。视频编码只裁去录制准备阶段并截取300秒，不使用截图作为视频输入，不插帧伪造水位或时间。

启动服务后，在正常监测状态运行：

```bash
./scripts/record-five-minute-demo.sh
```

新版过程与状态采样保存在 `narrated-recording.json`，其中记录原始连续 WebM 路径、解说节点及指针可见性检查。`narration-sync.json`记录配音、字幕文本匹配和时间对齐结果。解说脚本为`narration-cn.json`，已生成的音频与逐词时间戳在`voice/`，重新录制可复用。

如需修改配音文本，使用安装了`edge-tts`的独立Python环境运行`scripts/generate-demo-narration.py`重新生成相应片段；普通重新录制无需联网生成语音。

旧的 `TwinCitySafe-5min-demo.mp4` 是截图拼接版，`TwinCitySafe-5min-live-demo.mp4` 是无配音实录版，`TwinCitySafe-5min-narrated-demo.mp4` 是旧字幕版。当前请使用带 `final` 的单行字幕有声版，无需手动加载字幕文件。
