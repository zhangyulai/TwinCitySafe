# Milestone 10 最终完成报告

本报告采用本轮实际测试、生产演示与持久化档案，完整证据见 [M10验收](M10-verification.md)。

## 1. 项目最终状态

TwinCitySafe V1.0 比赛展示版本已完成并冻结核心功能。六大页面、两类事故闭环、正式演示控制与生产构建均通过本轮验证；当前服务运行在正常监测状态。没有新增核心场景或模型，没有重写 SceneManager、仿真引擎、预测、拓扑或回放。

入口：<http://127.0.0.1:5173/dashboard?demo=1>。后续进入比赛排练、材料制作和最终部署，已知模型与硬件性能边界保持公开。

## 2. 最终系统架构

前端采用 Vue 3、TypeScript、Pinia、Vue Router、Three.js 与 ECharts；后端采用 FastAPI、Pydantic、SQLAlchemy、PostgreSQL 和 Alembic。全局单 WebSocket 接收同一内存引擎的 1 Hz 实时状态，REST 承担资产、预测、比较、人工操作和历史查询。

设备异常使用原 Isolation Forest，内涝未来水位和风险使用原六个 XGBoost；拓扑隔离使用图搜索，当前风险使用参数化规则，应急方案使用同基线物理副本推演。Replay Store 独立读取持久化历史，不回写实时引擎。详见 [技术说明](TECHNICAL_OVERVIEW.md)。

## 4. Dashboard 优化

首页以中央 Web3D 为主视觉，两侧优先展示运行状态、实际在线/异常设备、管网状态、当前事故、预测与告警，下方提供真实事件和演示入口。设备统计来自当前三台仿真设备，不再采用旧系统汇总默认数；运行态为离散状态，不创造“综合安全指数”。

水位趋势纵轴随实际观测调整，避免事故水位被原固定上限截断。正常场景的 1920 浏览器实测三维宽约 1022 px，约为页面宽度 53.2%。页面来源和限制见 [数据审计](M10-data-source-audit.md)。

## 5. Web3D 优化

保留原场景、相机、物体与处置效果，改善默认镜头、建筑主体与屋顶的层次、地面和天气光照可读性。未增加 Bloom 或外部三维模型，未重写 SceneManager。

地上正常模式保持干净，地下保留既有透明与阴影优化；异常对象、影响范围和正常对象区分显示。质量切换改变绘制预算，不改变雨量、水位、设备、阀门或风险。详见 [Three.js Profile](final/M10-three-profile.md)。

## 6. Design System

共享深蓝黑背景、青蓝强调色、五级风险语义色、文字层级、卡片边框/圆角/间距及按钮状态。Header 集中展示品牌、六个导航入口、时间、后端、实时连接和当前事故状态，辅助操作包含系统状态、演示模式、全屏与平台说明。

ECharts 使用统一主题及组件管理，背景透明、单位分开，正常更新沿用 `setOption`。技术细节适度折叠，算法身份仍在模型详情可查。审查记录见 [UI 审计](M10-ui-audit.md) 和 [功能审计](M10-feature-audit.md)。

## 29. 8分钟演示流程

采用两类现场事故。前半程暴雨运行期间依次讲解运维、未来预测与模型边界；高风险时暂停比较，人工选择 B 并恢复时钟，待稳定后完成工单和关闭。后半程重置演示、启动泄漏，完成定位、隔离、稳定与关闭，再展示两类历史档案。

建议预算：0:00–3:15 暴雨监测/预测，3:15–5:20 比较/执行/稳定/关闭，5:20–7:20 泄漏闭环，7:20–8:00 关键回放与总结。与演示脚本一致，操作速度、暂停时长和设备性能会影响实际用时；本轮自动验收墙钟 **410.4s**，额外包含API批量计时与多尺寸截图，因此不是现场讲解承诺；需按 [演示脚本](DEMO_SCRIPT.md) 实机排练。

## 30. 最终项目亮点

1. 面向园区地上/地下空间的一体化 Web3D 数字孪生，将设备、气象、环境、管网与事故放在同一时空视图中。
2. 物理预测、仿真数据训练的风险预测与同基线反事实推演共同辅助判断，同时保留人工方案选择、环境假设和模型误差。
3. 从异常检测、风险演化、人工处置到工单关闭与历史回放的可追溯闭环，持续保留原始观测、动作、缺失项和遗留影响。

测试数量是工程可靠性证据，不替代上述创新点；项目不包装为大模型系统或真实园区生产部署。

## 31. 当前已知边界

平台是纯软件演示，示范资产、遥测、事故与训练样本不代表真实传感器或城市数据。内涝为简化水量守恒，管网为简化流量/压力及拓扑关系，不提供 CFD、EPANET、真实 GIS/BIM 或工程安全保证。

单 worker 内存引擎重启不恢复事故；未关闭事件标 ABORTED，有界重试不保证长期断库的全部中间历史。模型仅验证原仿真分布，人工干预与雨势回落可能扩大实际误差；Close 保留物理影响，不能解释为恢复正常。

旧历史缺失无法恢复，回放连续插值不是新增观测。工单采用字符串班组，无复杂权限、真实调度、LLM Agent、移动端或 PDF 导出。SwiftShader 性能不能替代比赛 GPU 实测，正式生产使用前仍需排练与设备检查。本轮全部软件验收已完成；实际比赛GPU和投屏条件仍需现场复验。1366回放视口边缘的长浮动标签可能裁切，对应数值在历史摘要完整显示；部分历史步骤仍保留动作枚举标识。
