# 浅色专业平台改版

用户已选择“浅色专业平台：留白充足，蓝灰配色，操作更清楚”。两个微信参考链接均返回“环境异常，需要验证”，未取得文章正文或参考图片；本版依据用户明确选择的方向重新组织现有产品界面，没有声称复刻文章。

后续参考了用户提供的[《数字孪生在智慧城市中的前端呈现与 UI 设计思路》](https://www.sohu.com/a/900212063_121896552)。本项目没有复制文章图片或版式，而是将其中的“三维模型与实时数据绑定、信息与控制分层、图表可读性、交互效率”落实为浅色界面上的科技网格、实时状态和数据面板。

## 科技化增强

- 页面背景采用低对比数据网格，侧栏和顶栏加入蓝—青状态轨；保留充足留白，避免变为难读的纯深色大屏。
- 首页标题增加实时数字孪生标识，四张关键指标卡引入数据编号、蓝青数据轨和轻微悬停反馈。
- 业务面板加入克制的 HUD 角标；Three.js 视口显示“DIGITAL TWIN / REALTIME RENDER”状态标识，模型视口继续使用深色以保证三维对象、标签和风险图层的对比度。
- 风险贡献条与内涝规则贡献条使用更清晰的轨道和数据色，数值、单位和已有业务含义不变。

## 指挥大屏版本

根据用户提供的智慧城市综合指挥中心参考图，界面已进一步切换为深蓝数字孪生指挥大屏：

- 顶部使用“智慧园区综合指挥中心”主标题、六个横向业务入口、实时连接与环境状态，桌面端不再使用左侧工作台导航。
- 中间保持真实 Three.js 园区模型为主视觉，左右两侧继续显示事故、告警和趋势；下方连接设备、气象、处置和档案信息。
- 所有页面采用深蓝半透明数据面板、霓虹蓝边框、角标、数据网格和发光状态轨；ECharts 同步切为暗色坐标轴、深色提示框和高对比数据线。
- 小屏仍保留横向可滚动的六个图标导航和原有响应式单列布局；不以图片替代页面，也未改变接口、模型、仿真或事件状态机。

## 统一工作空间

- 白色固定侧栏，六个业务入口使用统一线性图标，当前页高亮；中等桌面宽度收为图标和文字窄栏，小屏转为顶部导航。
- 顶栏展示当前位置、实时连接、时间与系统状态；演示控制与业务内容分层。
- 使用白色卡片、蓝灰背景、蓝色主操作、语义化风险色；统一边框、圆角、间距、表单与键盘焦点。
- 首页增加四项真实数据指标：设备在线、管网资产、当前场景风险、事件档案。无活动事故时风险显示缺省值，不编造园区综合分数。
- 首页三维视图成为主区域；当前事故、告警及水位趋势位于右侧，设备与环境详情移到下方。
- 运维、管网、风险、应急和复盘统一为浅色组件；拓扑图、趋势图、图例、标签、提示框适配浅色背景。
- 三维视口保留深色背景以维持模型、地下管线、积水和历史标签的对比度；外层工具栏采用浅色。
- 系统状态抽屉、关于平台、演示控制、事故提示、工单和报告采用相同视觉规范。

## 实现入口

- `frontend/src/App.vue`：统一工作空间外壳。
- `frontend/src/styles/workspace.css`：布局、响应式与公共组件规范。
- `frontend/src/style.css`：全局浅色语义变量。
- `frontend/src/components/shell/WorkspaceIcon.vue`：本地 SVG 导航图标，无外部图标请求。
- `frontend/src/views/Dashboard/index.vue`：首页信息分区及真实指标。
- `frontend/src/charts/theme.ts`：图表显示属性适配，不改序列数值、单位、坐标范围或回调。

后端接口、数据库结构、模型、仿真算法及事件状态机未修改。原有 M0–M10 验收记录和演示视频保留，新截图与结果位于 `docs/ui-light/`。
