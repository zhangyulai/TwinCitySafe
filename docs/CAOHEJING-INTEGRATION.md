# 漕河泾科技绿洲园区集成说明

本项目以漕河泾科技绿洲一至六期作为比赛展示的统一空间语境。公开 GIS 是六个既有业务板块共享的空间底座，不另设“园区 GIS”业务板块；综合态势、运维、地下空间、风险研判、应急推演和事件复盘均从同一个三维场景挂载 GIS 地面、建筑轮廓和道路映射。

## 数据分层

| 层级 | 内容 | 来源与边界 |
|---|---|---|
| 公开 GIS | 园区建筑轮廓、道路、水体、设施面 | OpenStreetMap 公开数据，WGS 84；见 `frontend/public/gis/README.md`。 |
| 参数化建筑 | 建筑高度、体量、窗格立面 | 公开高度/层数优先；缺失属性按园区常见研发办公建筑范围生成。不是 BIM、竣工资料或实景模型。 |
| 软件仿真资产 | P01/P02/P03、B2 内涝区、地下管网、阀门、泄漏和应急动作 | 仅用于空间联动演示，不代表园区真实设备、地下设施或实时物联网数据。 |

## 展示映射

| 内部稳定 ID | 页面展示名称 |
|---|---|
| `A-OFFICE` | 办公楼 A（仿真映射） |
| `B-RESEARCH` | 科研楼 B（仿真映射） |
| `C-LAB` | 实验楼 C（仿真映射） |
| `D-SERVICE` | 综合服务楼（仿真映射） |
| `B2-PARKING` | B2 地下停车场（仿真区） |

资产 ID 保持不变，因此既有 WebSocket 字段、数据库档案、算法训练结果、自动化验证和历史回放仍可复现。历史事故保留产生当时的原始名称；前端会按稳定 ID 显示统一的园区映射名称。

## 运行

```bash
./prepare-demo.sh
./start-demo.sh
```

打开任一业务页面即可查看共享 GIS 场景；“二维 GIS”仅是同一空间底座的辅助查看方式。`VITE_ENABLE_ONLINE_GIS=true` 时会请求 OpenStreetMap 在线瓦片；网络不可用或关闭该开关时保留项目内置的公开 GIS 矢量底座。

公开园区基础信息参考[漕河泾科技绿洲官方介绍](https://chj.shlingang.com/chj/yqgk/qyzt/)；地理要素遵循 [OpenStreetMap ODbL 1.0](https://www.openstreetmap.org/copyright)。
